# Placementor – AI-Based Placement Prediction System

## 1. Project Overview

Placementor is an AI-based Placement Prediction System designed to help students understand their placement readiness and improve their chances of getting placed.

The system uses Machine Learning techniques to analyze students' academic performance, technical skills, aptitude scores, internships, and other relevant factors to predict placement outcomes.

It also provides separate dashboards for students and faculty to monitor performance and analyze placement trends.

## 2. Objectives

- Predict student placement outcomes using Machine Learning.
- Analyze academic and technical performance.
- Identify skill gaps among students.
- Help students improve their placement readiness.
- Provide faculty with placement analytics and reports.

## 3. Key Features

- Student Dashboard
- Faculty Dashboard
- ML-Based Placement Prediction
- Student Performance Analytics
- Skills Gap Analysis
- Placement Statistics and Reports
